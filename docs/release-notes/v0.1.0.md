最初の公開版です。

GoPro を USB でつなぐと、microSD を抜かずに写真・動画を PC へ取り込めます。
カメラ側は完全リードオンリーで、削除・変更は一切しません。

## できること

- `gpget sync` — 未取得のメディアを日付フォルダへ取り込む
- `gpget status` / `list` — カードの中身と、まだ取り込んでいない量を見る
- `gpget get` — ファイル名やワイルドカードで個別に取る
- `gpget autostart` — カメラを挿したら自動で取り込む(任意)

グループ(バースト / タイムラプス / インターバル)は 1 単位で扱い、
カメラ側で削除されたフレームは除外します。転送は `.part` に書いてから
バイト数を検証して確定し、中断した転送は次回に再開します。

## 検証状況

**macOS(Apple Silicon / macOS 15 以降)は実機で検証済みです。**
GoPro MISSION 1 PRO ILS(FW H26.03.03.00.00)で、106 ファイル / 約 400MB の
取り込みと自動起動を確認しています。

**Windows と Linux はビルドしているだけで、実機で動かせていません。**
手動の取り込みは同じコードを通りますが、自動起動(タスクスケジューラ /
systemd user timer)は一度も動作確認できていません。

試していただける方は `docs/testing.md` に手順と報告方法をまとめてあります。
うまくいかなかった場合の報告も歓迎します。

## 対応環境

| OS | アーキテクチャ | 下限 |
|---|---|---|
| macOS | Apple Silicon | macOS 15 |
| Windows | x64 | Windows 10 |
| Linux | x86_64 / aarch64 | systemd(自動起動を使う場合) |

カメラは MISSION 1 PRO ILS で検証。`/gopro/media/list` を有線で公開している
機種(MISSION 1 系 / HERO11〜13 / MAX2 など)でも動く見込みですが、未確認です。

## インストール

**ブラウザではなく `curl` で取得してください。** ブラウザ経由だと macOS で
検疫属性が付き、署名していない gpget は Gatekeeper に止められます。
コマンドは README を参照してください。

## 注意

バージョンが 0.x の間は、コマンドの形や設定ファイルの項目が変わることがあります。
